xwalk demo

Text to ontology terms

Paste some text. A language model extracts chemicals, diseases, genes and foods, then xwalk retrieval (BM25 keyword search plus dense embeddings, fused by rank) looks each one up in a matching ontology: ChEBI, CTD diseases, NCBI Gene or FoodOn.

Each ontology here is a 200-term sample, not the full vocabulary, so many real-world terms will not be found. Candidate IDs always come from the sample; the model never writes them.
